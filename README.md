# kvcells-target-public

## Machine Learning Pipeline for Bioactivity Prediction

Repositorio público de apoyo al desarrollo de un pipeline reproducible para el procesamiento de datos y la predicción de bioactividad mediante técnicas de aprendizaje automático.

El proyecto forma parte de un trabajo de investigación orientado al análisis de bioactividad y a la aplicación de modelos de aprendizaje automático para apoyar procesos de predicción y clasificación de compuestos bioactivos.

## Objetivo

Desarrollar y documentar un flujo computacional reproducible que permita realizar las principales etapas del análisis:

1. Limpieza y preparación de los datos.
2. Entrenamiento de modelos de aprendizaje automático.
3. Generación de predicciones.
4. Evaluación y análisis de los resultados.
